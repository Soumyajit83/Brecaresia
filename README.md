This study developed and validated a markerless, cross-platform computer vision and machine learning framework for automated kinematic assessment and objective functional tracking in post-operative breast cancer rehabilitation. Traditional clinical evaluations rely heavily on subjective manual goniometry and questionnaires, introducing inter-observer variability and failing to capture dynamic, continuous joint trajectories. To resolve this, our contactless framework employs a YOLO-based pose estimation architecture optimized to extract multi-axis kinematics directly from standard monocular video feeds. Extracted kinematic metrics were evaluated using unsupervised K-means clustering and supervised classifiers (Random Forest, SVM, and XGBoost) to stage functional recovery. To bypass hardware constraints on consumer devices (iOS, Android, and laptops), an asynchronous WebSocket cloud architecture offloaded computation to a backend GPU pool. Technical validation demonstrated high spatial fidelity, achieving a joint localization mean absolute error of 4.8 mm against ground-truth reference videos. Biomechanical tracking across a seven-exercise protocol in 18 participants captured significant movement impairments; the post-operative cancer cohort exhibited marked reductions in mean chest expansion angles compared to healthy controls (72.2 ± 5.4° vs. 88.3 ± 2.9°, p < 0.001). For functional progress staging, the K-means clustering engine achieved the highest diagnostic accuracy of 95.6% (AUC = 0.825) across distinct clinical recovery tiers. Furthermore, the distributed cloud system delivered real-time streaming latency under 45 ms across all consumer platforms. This markerless framework eliminates the logistical barriers of conventional motion laboratories, providing an accurate, scalable platform for remote telerehabilitation and exercise oncology monitoring.
